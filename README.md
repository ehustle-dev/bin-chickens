# Bin Chickens

Joke site for Bin Chickens, a WoW Forever guild. One static page at the repo root: navy, gold, and a loot system called the Suptatorship.

Not affiliated with Blizzard Entertainment. Nothing on the page takes payment.

Preview locally from the repo root:

```bash
python3 -m http.server
```

GitHub Pages publishes that same root on pushes to `main`.
